# past-ayx-notes

这是一个用于归档与发布独立 HTML 页面的仓库。仓库中存放的页面内容不涉及任何特定网站或域名，每个 HTML 文件均为独立的静态页面，用于记录、展示或测试用途。

## 项目简介

本仓库主要用于保存过去整理或编写的 HTML 页面，以便于后续查阅、分享或部署。所有页面均为纯前端静态文件，不依赖后端服务，可直接在浏览器中打开运行。

## 目录说明

```
/
├── index.html          # 仓库入口页面（如有）
├── pages/              # 存放主要 HTML 页面的目录
├── assets/             # 页面引用的静态资源（如图片、样式表、脚本文件）
└── README.md           # 本文件
```

- `pages/`：包含多个独立 HTML 文件，每个文件对应一个归档页面。
- `assets/`：存放页面所需的资源文件，按需组织子目录。

## 页面归档说明

- 每个 HTML 文件均为完整页面，可独立运行。
- 页面间无依赖关系，无跨站引用。
- 部分页面可能包含实验性或临时性内容，仅供存档参考。

## 维护说明

- 本仓库不定期更新，仅用于归档已有页面，不承诺持续维护或更新。
- 如发现页面存在显示异常或链接失效，欢迎提交 Issue 反馈。
- 不接受针对具体内容的修改请求，除非涉及严重的显示错误。

## 使用方式

1. 克隆或下载本仓库到本地。
2. 使用浏览器直接打开任意 `.html` 文件即可查看。
3. 也可将仓库部署到静态托管服务（如 GitHub Pages）进行在线访问。

## 许可

本仓库内容仅供个人存档与学习参考，不构成任何形式的使用授权。如需引用或分发，请自行评估合规性。
